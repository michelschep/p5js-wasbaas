# 🧺 Was-hulp voor de Zielige Man

> Een p5.js interactieve waskaart voor mannen die plotseling alles zelf moeten doen.

## Wat doet het?

Klik op een kledingstuk (sokken, t-shirt, trui, broek, spijkerbroek, ondergoed, handdoek) en ontdek:

- 🌡️ Op hoeveel graden wassen
- 🔄 Welk wasprogramma
- 🧴 Hoeveel wasmiddel
- 💨 Hoe drogen (en waarom NOOIT de trui in de droger)
- ✅ Wat mag samen in de machine
- ❌ Wat nooit samen mag (jeans + wit shirt = roze shirt)
- 🎨 Kleurgroep tips

En als het allemaal te veel wordt: **🚨 Bel Mama**.
